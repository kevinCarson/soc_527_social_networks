This repository contains the lecture materials from my guest lecture series on inferential network methods for the SOC: 527 *Social Networks* Ph.D. course at the University of Arizona (FALL 2026). Please feel free to use these materials for your own class and research! 

If you spot any errors or mistakes, please do not hesitate to reach out via email (kacarson@arizona.edu)! Additionally, if you have any questions about the course materials, please feel free to reach out (I'm always happy to talk about network methods). 

I hope you find these materials helpful for conducting your research (or teaching your own graduate courses on inferential network methods).
